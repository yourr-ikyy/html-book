Chapter 01

🧱 HTML itu sebenarnya apa?

HTML adalah singkatan dari HyperText Markup Language. Gampangnya, HTML adalah bahasa markup yang dipakai untuk memberi tahu browser, “ini judul”, “ini paragraf”, “ini gambar”, “ini tabel”, dan seterusnya.

HTML bukan bahasa untuk mengatur warna, layout, atau animasi. HTML mendefinisikan struktur dan makna (semantik) konten, sedangkan CSS mengatur presentasi dan JavaScript biasanya menangani perilaku dinamis. Karena itu halaman web biasanya punya HTML untuk struktur, CSS untuk tampilan, dan JavaScript untuk perilaku/interaksi.

🎯 Bayangkan website sebagai rumah

HTML = rangka rumah.

CSS = cat, furniture, dekorasi.

JavaScript = pintu otomatis, lampu, tombol yang bekerja.

Jadi saat soal bertanya “apa fungsi HTML?”, jawabannya berhubungan dengan struktur/markup konten halaman web.
Chapter 02

🏗️ Struktur HTML paling dasar

Pelajari bagian-bagiannya, jangan sekadar menyalin.

index.html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Halaman Saya</title>
</head>
<body>
  <h1>Halo!</h1>
  <p>Ini isi halaman.</p>
</body>
</html>

🔎 Dibaca dari atas ke bawah

1. <!DOCTYPE html> memberi tahu browser bahwa dokumen menggunakan HTML. Di HTML modern, ini adalah deklarasi HTML5.

2. <html> adalah elemen paling luar/root dari dokumen HTML.

3. <head> berisi informasi tentang dokumen, misalnya title, metadata, dan resource tertentu.

4. <body> berisi konten utama yang tampil di halaman.

Chapter 04
⚙️ Attributes

  

    
Attribute/atribut adalah informasi tambahan yang diletakkan pada tag pembuka. Atribut membantu memberi detail, misalnya ke mana link pergi, file gambar ada di mana, atau sebuah input harus berjenis apa.

    
<a href="https://example.com" target="_blank">
  Buka website
</a>

    
Pola sederhananya adalah attribute="value". Tetapi ada juga boolean attributes seperti required, disabled, checked, dan controls yang bisa ditulis tanpa value.

  






  
Pahami bedanya

  
🪪 id vs class

  
id biasanya dipakai sebagai identitas unik untuk satu elemen tertentu.

  
class dipakai untuk mengelompokkan elemen yang punya gaya/perilaku sama dan dapat digunakan oleh banyak elemen.

  
<h1 id="judul">Hello</h1>
<p class="info">A</p>
<p class="info">B</p>

Chapter 05 • IMPORTANT
📊 TABLE, bagian yang wajib paham ⭐
Jangan cuma hafal nama tag. Pahami hubungan antar tag.

  
Rumus paling penting: <table> = wadah tabel → <tr> = baris → <th> = header → <td> = data.

  

    

      

        
Table basic

        
<table border="1">
  <tr>
    <th>Nama</th>
    <th>Nilai</th>
  </tr>
  <tr>
    <td>Alya</td>
    <td>95</td>
  </tr>
</table>

      

    

    

      
Kenapa ada tr, th, td?

      
Bayangkan tabel sebagai grid. tr adalah satu garis horizontal/baris. Di dalam tr, kita menaruh sel. th dipakai untuk sel yang menjadi judul/header, sedangkan td dipakai untuk data biasa.

      
border="1" sering muncul di contoh dasar sekolah, tetapi pada website modern border biasanya diatur menggunakan CSS.

    colorrangesubmit
    resetbutton
  

  
Contoh: <input type="email"> membuat kontrol input yang ditujukan untuk alamat email.
